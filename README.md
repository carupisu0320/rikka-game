# 六華（リッカ）オンライン対戦

麻雀の体験をシンプルに再構築したボードゲーム「六華」のオンライン対戦実装です。

## 🎮 今すぐ遊ぶ

👉 **[https://carupisu0320.github.io/rikka-game/](https://carupisu0320.github.io/rikka-game/)**

ボット対戦はブラウザだけですぐ遊べます。オンライン対戦はルームIDを友達に共有してください（2〜5人）。

## 🎆 ゲームルール

### 概要
- プレイ人数：2〜5人
- 目標：設定した点数（5 / 10 / 15 / 20 / 30 から選択、デフォルト10点）を先取したプレイヤーが勝利

### 牌について
リッカ牌はドミノ牌で、上下に1〜6のシンボルが描かれています。
手牌の「上」の面を使って役を作りますが、牌を**反転**させると上下が入れ替わります。
上下の数字が同じ牌（例: 上3・下3）は**★ゾロ目牌**と呼ばれ、ボーナスの対象になります。

### 手番の流れ
1. 場の牌を1枚選んで引く（裏向き山札 or 表向き場から）
2. 手牌6枚から不要な1枚を捨てる（表向きで場に置く）
3. 役が完成したら「上がる！」を宣言

### 役の種類（基本役・常に有効）
| 役名 | 条件 | 点数 |
|------|------|------|
| 一色 | 6枚の下の数をすべて同じに（上は何でもOK） | 2点 |
| 三連 | 「下が同じ3枚＋上が連番」のセットを2組 | 3点 |
| 六華 | 6枚の下の数が同じ＋上が1〜6の連番 | 6点 |

### 役の種類（追加役・ロビーでON/OFF可能）
| 役名 | 条件 | 点数 |
|------|------|------|
| 三対 | 6枚を同じ牌のペア×3組にする | 5点 |
| 三色 | 全牌の上下の数を3種類のみにする（ボーナスなし・ついでに完成でのみ成立） | 3点 |
| 輝光 | 6枚すべてを★ゾロ目牌にする（ボーナスなし） | 5点 |
| 無双 | ★ゾロ目牌を6種類すべて集める | 3点＋★ボーナス |

### ★輝きボーナス
上がったとき、手牌に★ゾロ目牌（上下が同じ数字の牌）があると、その枚数分だけ役の点数に**+1点ずつ**追加される（輝光を除く）。

### 追加ルール（ロビーでON/OFF可能）
- **ついでに完成**：誰かが上がった後、表向きの捨て牌と自分の手牌を組み合わせて役が完成していれば、その得点がもらえる。
- **リーチ**：捨てればテンパイ（あと1枚で上がれる状態）になるときに宣言可能。以降は自動で捨て牌され、上がると+1点。
- **ロン**：他のプレイヤーが捨てた牌で自分の役が完成するなら宣言可能。手番順を無視してその牌をもらい、その場で上がれる。
  - 得点（役点＋ボーナス）はストックからではなく、**捨てた本人の得点チップ**から奪う。
  - 相手の点数が足りない場合は**奪えるだけ奪う**（相手が0点なら何ももらえない）。
  - 2人以上が同時にロンを宣言した場合は、**捨てた人から時計回りで最も近い1人のロンだけが有効**。

## 🌐 デプロイ構成

このプロジェクトはフロントエンドとオンライン対戦サーバーを分けてホストしています。

- **フロントエンド（index.html）**：GitHub Pages（[carupisu0320.github.io/rikka-game](https://carupisu0320.github.io/rikka-game/)）
- **オンライン対戦サーバー（server.js）**：Render.com（WebSocketサーバーとして常時稼働）

GitHub PagesはNode.jsを実行できない静的ホスティングのため、`server.js` は別途Render.com等でホストする必要があります。

### 1. GitHubにプッシュ
```bash
git init
git add .
git commit -m "Initial commit: 六華オンライン対戦"
git branch -M main
git remote add origin https://github.com/carupisu0320/rikka-game.git
git push -u origin main
```

### 2. Render.comでデプロイ（server.js用）
1. [render.com](https://render.com) にアクセスしてアカウント作成
2. 「New Web Service」をクリック
3. GitHubリポジトリを接続
4. 以下の設定を入力：
   - **Name**: `rikka-online`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
5. 「Create Web Service」をクリック

Renderの無料プランで動作します！デプロイ後、自動でURLが発行されるので、`index.html` 側のSocket.io接続先をそのURLに合わせてください。

### 3. GitHub Pagesでデプロイ（index.html用）
リポジトリの Settings → Pages で公開ブランチ・フォルダを指定するだけで、`https://carupisu0320.github.io/<リポジトリ名>/` で公開されます。

### 4. 友達と遊ぶ
- 公開されたURLをブラウザで開く
- ルームIDを決めて友達に共有
- 2〜5人でプレイ可能！

## 🔧 カスタマイズ

### 追加ルールの実装
新しい役を追加したい場合は、`checkWin` 関数（オンライン対戦は `server.js`、ボット対戦は `index.html`）に判定関数を追加し、`optRoles` の選択肢に組み込めます。

### スコア目標の変更
目標点はロビー画面で5 / 10 / 15 / 20 / 30から選択できます。選択肢自体を変えたい場合は `server.js` の `goal` 判定部分を編集してください。
